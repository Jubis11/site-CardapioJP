# Uso do Bootstrap no Projeto
Neste projeto, o **Bootstrap 5** foi utilizado para garantir uma estrutura responsiva, layout padronizado e desenvolvimento ágil:

* **Sistema de Grid (`container`, `row`, `col-*`):** Organização das seções em colunas adaptáveis para desktops e celulares.
* **Flexbox Utilities (`d-flex`, `justify-content-between`, `align-items-center`):** Alinhamento dos elementos no cabeçalho, navegação e rodapé.
* **Componentes (`card`, `btn`):** Estruturação dos itens do cardápio e blocos informativos com bordas arredondadas e sombras suaves (`shadow-sm`).
* **Utilitários de Espaçamento (`py-*`, `mb-*`, `g-*`):** Controle padronizado de margens e espaçamentos.
* **Tipografia e Classes Auxiliares (`text-center`, `fw-bold`, `text-muted`):** Formatação rápida de títulos e descrições diretamente no HTML.
* **Estrutura de Layout (`min-vh-100`, `flex-grow-1`):** Fixação do rodapé na parte inferior da tela em todas as páginas.
